# PROJETO-MESAFARTAI
O MESAFARTAI é uma plataforma desenvolvida em Python que utiliza Inteligência Artificial para conectar doadores de alimentos a ONGs, 
abrigos e instituições que atendem pessoas em situação de vulnerabilidade. O sistema busca facilitar e agilizar as doações, 
identificando alimentos disponíveis e direcionando-os para instituições próximas que necessitam desses recursos.
O projeto está alinhado à ODS 2 da ONU – Fome Zero e Agricultura Sustentável, pois contribui para a redução do desperdício de alimentos e para ampliar o acesso à alimentação,
utilizando a tecnologia como ferramenta de apoio no combate à fome.
